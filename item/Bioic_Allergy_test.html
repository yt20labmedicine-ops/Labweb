檢驗項目明細
 

檢驗項目

特異過敏原免疫試驗（Bioic Allergy test）

  
 

檢驗表單

特異性免疫球蛋白過敏原檢查(CM-1714)

  
 

參考範圍

測定單位AU與Class分級對照
Class 0，<1 AU；
Class 1，1-2 AU；
Class 2，2-4 AU；
Class 3，4-8 AU；
Class 4，8-16 AU；
Class 5，16-32 AU；
Class 6，>32 AU

  
 

採檢容器及檢體量
黃頭管/血液
血液採檢量3-4mL
  
  
 

採檢注意事項

1.採血後倒轉試管5-6次。

  
 

檢驗方法

化學冷光免疫檢測(CLIA)

  
 

檢驗效能

N/A

  
 

負責組別

血清免疫組#1238、1299

  
 

報告完成時間

3工作天

  
 

臨床意義

檢驗40項過敏原包括，D1 屋塵蟎、D2 粉塵蟎、D201熱帶無爪蟎、IX 蟑螂、E1 貓毛、E5 狗毛、F1 蛋白、F2 牛奶、F3 鱈魚、F4 小麥、F13 花生、F14 大豆、F20 杏仁、F23 蟹、F24 蝦、MX黴菌、M5 白色念珠菌、G2 狗牙根草、G6 梯牧草、W1 豬草、E85雞毛、E86鴨毛、W6艾草、W12 菊科植物、F25番茄、F31胡蘿蔔、F35馬鈴薯、F37孔雀蛤、F41鮭魚、F45酵母菌、F47大蒜、F75蛋黃、F81乳酪(乾酪型)、F84 奇異果、F300羊奶、T18尤加利樹、T19相思樹、A1 小黑蚊、A2芋頭，測定病患血清中的特異性免疫球蛋白IgE是否對這些過敏原反應，若檢測值>1AU，表示可能對其中該種或多種過敏原會產生過敏。

  
 

加驗時效

開立預留醫令並採檢後，一個月內可加驗
